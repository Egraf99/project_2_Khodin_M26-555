# Primitive DB

Учебное консольное приложение для управления таблицами и записями.
Данные сохраняются в JSON-файлах. Поддерживаются типы `int`, `str` и `bool`.

## Установка и запуск

Нужны Python 3.12 или новее и [uv](https://docs.astral.sh/uv/).
Выполняйте команды из корня проекта:

```bash
uv sync
mkdir -p data
uv run database
```

При активированном окружении приложение также запускается командой `database`.

## Управление таблицами

```text
create_table users name:str age:int is_active:bool
list_tables
info users
drop_table users
```

- `create_table` создает таблицу с заданными столбцами и добавляет `ID:int`.
- `list_tables` показывает названия существующих таблиц.
- `info` показывает название, столбцы и количество записей таблицы.
- `drop_table` удаляет таблицу из метаданных после подтверждения.
- `help` выводит справку, `exit` завершает программу.

## CRUD-операции

### Добавление записи

```text
insert into users values ("Sergei", 28, true)
insert into users values ("Anna", 30, false)
```

Все поля обязательны. Значения передаются в порядке столбцов, без `ID`.
ID генерируется автоматически: максимальный существующий ID + 1.
Количество и типы значений проверяются по структуре таблицы.

### Чтение записей

```text
select from users
select from users where age = 28
select from users where is_active = false
```

Результат выводится в консоль с помощью `PrettyTable`.

### Обновление записей

```text
update users set age = 29 where name = "Sergei"
update users set age = 31, is_active = true where name = "Anna"
```

Все записи, подходящие под условие, обновляются и сохраняются в файл таблицы.

### Удаление записей

```text
delete from users where ID = 1
```

После подтверждения подходящие записи удаляются, а оставшиеся сохраняются в файл.

### Значения и условия

Строки записываются в кавычках, числа — без кавычек, логические значения —
`true` или `false`. Например, `28` — число, а `"28"` — строка.
Строки могут содержать пробелы и запятые.

Для `where` и `set` используются пары `столбец = значение`.
Несколько пар разделяются запятыми. В `where` должны совпасть все условия:

```text
select from users where age = 29, is_active = true
```

## Декораторы и кэширование

- `handle_db_errors` обрабатывает ошибки файлов, отсутствующих таблиц и столбцов,
  а также некорректных значений. Сообщение выводится в консоль, после чего можно
  вводить следующую команду.
- `confirm_action` запрашивает подтверждение перед `drop_table` и `delete`.
  Только ответ `y` выполняет действие. Любой другой ответ отменяет его.
- `log_time` измеряет время успешного выполнения `insert` и `select`
  через `time.monotonic()`:

  ```text
  Функция select выполнилась за 0.001 секунд
  ```

- `create_cacher` хранит результаты одинаковых запросов `select` в замыкании.
  Повторный запрос использует кэш, поэтому повторного сообщения о времени
  выполнения `select` нет. После команд изменения таблиц или записей кэш
  сбрасывается. При новом запуске программы кэш создается заново.

## Хранение данных

- `db_meta.json` — названия таблиц и структура столбцов.
- `data/<имя_таблицы>.json` — список записей отдельной таблицы.

Пути отсчитываются от текущей папки запуска, поэтому запускайте приложение
из корня проекта. При отсутствии файла таблицы загрузка возвращает пустой список.

`drop_table` удаляет описание таблицы; файл с ее записями остается в `data/`.

```bash
uv run ruff check .
```

## Сборка и установка пакета

```bash
uv build
uvx twine check dist/*
source .venv/bin/activate
uv tool install dist/*.whl
```

После установки команда `database` доступна как отдельный инструмент.
Запускайте ее из папки проекта с директорией `data/`.
Если команда не найдена, выполните `uv tool update-shell` и перезапустите терминал.
